# Macroeconomic Drivers of EUR/USD: Beyond the Yield Spread

This project investigates the macroeconomic determinants of EUR/USD exchange rate movements using data science and econometric techniques.

## Variables Included

### United States
- CPI Inflation
- Nonfarm Payrolls
- Unemployment Rate
- Retail Sales
- ISM Manufacturing PMI

### Euro Area
- HICP Inflation
- Unemployment Rate
- Manufacturing PMI

### Financial Variable
- US 2-Year Treasury Yield minus German 2-Year Government Bond Yield

### Target Variable
- Daily EUR/USD Returns

## Sample Period
March 2016 – March 2026
